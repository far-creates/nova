# Role Matrix

## Roles

- guest
- learner
- creator
- admin

## Permissions

### Guest

- can use hero practice
- can generate guest attempts
- can keep local and backend guest history

### Learner

- all guest capabilities
- authenticated progress tracking
- review sessions
- profile history and analytics

### Creator

- learner capabilities
- upload and manage approved content

### Admin

- full platform content control
- creator verification
- moderation and reporting

## Future Rule

Any learner may later become a creator. The permission model must remain role-based and not rely on page-specific hacks.
